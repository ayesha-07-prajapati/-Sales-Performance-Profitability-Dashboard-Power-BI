
# 📊 Sales Performance & Profitability Dashboard (Power BI)

## 📌 Project Overview
This interactive, multi-page **Power BI Dashboard** provides a comprehensive analysis of retail sales, profitability, discount strategies, and product performance. Designed for business stakeholders, it helps identify key revenue drivers, high-margin regions, and loss-making products to support data-driven decision-making.



---

## 🔑 Key Performance Indicators (KPIs)
* **Total Sales:** $2.30M
* **Total Profit:** $286.40K
* **Total Orders:** 9,994 (9.994K)
* **Total Quantity Sold:** 38K Units
* **Overall Profit Margin:** 12.47%

---

## 🛠️ Tools & Features Used
* **Microsoft Power BI Desktop:** Data modeling, DAX calculations, and custom visual formatting.
